# Security

This library authenticates against TickTick using your own credentials or session cookies, held only in memory and in the local cookie cache file you configure. It never sends your credentials anywhere other than TickTick's own servers.

If you find a security issue (e.g. credentials logged somewhere they shouldn't be, or a request that leaks more data than expected), please open a private report via [GitHub's security advisory form](https://github.com/OliverStoll/ticktick-api-v2/security/advisories/new) rather than a public issue.
